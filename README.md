# Рыбалка в Одессе — энциклопедия рыбака

Офлайн-справочник (PWA) по рыбалке в Одессе и Одесской области: виды рыб, наживки, снасти, способы ловли, места, сезонный календарь, правила любительского рыболовства и личный журнал уловов.

Сайт: https://watithemint.github.io/odesa-fishing/
